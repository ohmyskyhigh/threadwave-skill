# English UI Phrases

Use these stable user-facing labels when English is selected. Add only the lines relevant to the current state.

```text
State: ready | waiting for you | needs approval | blocked | scheduled | complete
Completed: <verified steps only>
Preflight: <suite, CLI, compatibility, setup, selected capability>
Review: <full proposal or exact content and target>
Problem: <stable code and plain-English meaning>
Waiting for you: <one user action>
Harness setup guide: https://www.threadwave.xyz/cli/setup/agent.md
Next: <one next step>
If you approve, I will run: <exact command template>
Issue report: generated for copy/paste; nothing was sent.
```

Never describe a dry-run as posted, replied, queued, or scheduled. Use `scheduled` only when an exact scheduler result includes a reservation. Use `complete` for a manual mutation only when returned evidence proves the outcome.
